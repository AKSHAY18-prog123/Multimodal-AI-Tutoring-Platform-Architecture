# System Architecture Specification

## Overview
SynapseTutor is a production-grade Intelligent Tutoring System (ITS) developed for Multimodal AI Hackathon 2026 (Track D). It unifies source-grounded multimodal retrieval, Bayesian Knowledge Tracing (BKT), multi-tier cognitive memory, and adaptive assessment.

## Key Architectural Layers

### 1. Ingestion & Canonical Source Tracking
- **PDF Processor**: `PyMuPDF` extracts text blocks, headings (font-size heuristics), tables, math expressions, and embedded images with exact `page_number`.
- **PPTX Processor**: `python-pptx` extracts slide text, titles, bullet lists, notes, and shapes with exact `slide_number`.
- **Video & Audio Processor**: Segmentation into timestamped chunks (`timestamp_start`, `timestamp_end`, formatted strings `MM:SS`).
- **Vision Analyzer**: Evaluates diagrams and flowcharts, extracting structured entities, relations, and pedagogical concepts.
- **Canonical Source Anchoring**: Every generated knowledge chunk carries immutable metadata connecting back to the exact location in the original file.

### 2. Grounded Multimodal RAG Pipeline
1. **Query Intent & Scope Analyzer**: Evaluates whether the question is on-topic, off-material, or chit-chat.
2. **Hybrid Retrieval**: Combines dense vector cosine similarity (ChromaDB) with BM25-style keyword density.
3. **FlashRank Reranking**: Re-scores candidate passages to isolate the top-5 most relevant chunks.
4. **Citation Validation Engine**: Cross-references citations generated by the LLM against retrieved chunks to guarantee zero fake citations.
5. **Strict Refusal Mechanism**: Blatantly off-material questions are strictly refused unless the user explicitly requests labeled *Outside Knowledge*.

### 3. Cognitive Learner Modeling
- **Bayesian Knowledge Tracing (BKT)**:
  - Novice prior $P(L_0) = 0.15$.
  - Real-time posterior updates on evidence.
  - Evidence weighting: Exam (1.0), Short answer (0.7), Conversation (0.3).
  - Half-life forgetting decay model.
- **ML Classifier (Random Forest)**: Predicts learner readiness state (*ready for next*, *needs practice*, *prerequisite remediation*).
- **ML Regressor (Gradient Boosting)**: Predicts expected quiz score and study minutes to reach 80% mastery.

### 4. Three-Tier Memory Architecture
- **Short-Term Memory**: Ephemeral sliding window of the active conversation.
- **Long-Term Memory**: Persistent learner profile and topic masteries in relational SQLite.
- **Episodic Memory**: Semantic chronological log of learning struggles and resolved misconceptions.

### 5. Multi-Provider AI Abstraction
- Supports **Google Gemini** (Gemini 2.0 Flash / Pro) as default.
- Supports **Ollama** for local execution.
- Deterministic **Mock Fallback** for zero-cost offline testing and CI.

### 6. First-Time Learner Lifecycle & Zero Fake Data
- **Dynamic Onboarding Detection**: Checks database on startup (`GET /api/v1/users/status`). If no profile exists, triggers modal: *"What should we call you?"*.
- **Database Source of Truth**: Stores learner record in `users` table with relational foreign keys across courses, chats, memories, and assessments.
- **Clean Cold Start**: Brand-new accounts start with 0 courses, 0% uncalibrated mastery, 0 study minutes, and genuine empty state cues.

### 7. General-Purpose / Subject-Agnostic Engine
- Works dynamically with **any academic subject** (Operating Systems, Computer Networks, Physics, Chemistry, Economics, Medicine, etc.).
- Topic discovery, concept extraction, prerequisite DAG construction, and adaptive assessments are dynamically generated from user-uploaded materials rather than pre-baked domain rules.
