2. Core AI & Machine Learning Techniques Used
Technique 1 • Knowledge Ingestion

Multimodal Parsing & Canonical Source Anchoring

  • PDF Documents (PyMuPDF / fitz): Extracts text blocks, section headings, markdown tables, mathematical equations, and embedded diagrams with exact page numbers.
  • Slide Decks (python-pptx): Extracts slide titles, hierarchical bullet points, tables, and speaker notes mapped to exact slide numbers.
  • Lecture Videos (yt-dlp, faster-whisper): Segments transcripts into timestamp intervals (MM:SS - MM:SS).
  • Zero-Hallucination Citation Anchoring: Every vector chunk retains immutable provenance metadata ([Source: Module 1 • Slide 24]). Clicking any citation in chat opens the exact slide/page in the slide-over Source Viewer Drawer.
Technique 2 • Grounded Retrieval

Hybrid RAG + Cross-Encoder Reranking + Strict Refusal

  • Dialogue Contextualization: Rewrites ambiguous follow-up prompts (e.g., "Give a calculation example") using sliding short-term history before retrieval.
  • Hybrid Retrieval: Combines Dense Vector Similarity (ChromaDB + sentence-transformers/all-MiniLM-L6-v2) with BM25 Lexical Keyword Density to capture both semantic meaning and exact formulas/acronyms.
  • FlashRank Reranking: Re-scores candidate chunks via a cross-encoder before prompt assembly.
  • Off-Material Guardrail: Strictly refuses out-of-syllabus queries ("This topic is not covered in the uploaded course material") while offering an opt-in Labeled Outside Knowledge button.
Technique 3 • Cognitive Student Modeling

Bayesian Knowledge Tracing (BKT) & Scikit-Learn ML

Tracks per-concept mastery probability $P(L_t)$ initialized at $P(L_0) = 0.15$ for novices:

$$P(L_t \mid \text{Correct}) = \frac{P(L_t)(1 - P(S))}{P(L_t)(1 - P(S)) + (1 - P(L_t))P(G)}$$ $$P(L_{t+1}) = P(L_t \mid \text{Obs}) + \bigl(1 - P(L_t \mid \text{Obs})\bigr) \cdot P(T)$$
  • Evidence-Weighted Updates: Full Quiz = 1.0 weight, Short Answer = 0.7, Chat Question = 0.3, plus Ebbinghaus forgetting decay.
  • Random Forest Classifier: Predicts pedagogical readiness state (ready_for_next, needs_practice, prerequisite_gap).
  • Gradient Boosting Regressor: Predicts expected quiz score and study minutes required to reach 80% target mastery.
Technique 4 • Memory & Self-Verification

3-Tier Cognitive Memory & Self-Verifying Assessments

  • Short-Term Memory: Active session sliding turn buffer for multi-turn conversational coherence.
  • Long-Term Memory: SQLite relational mastery store + dynamic Learning Behavior Profile (automatically switches to intuitive_analogy_first when confusion signals are detected).
  • Episodic Memory: Timestamped log of confusion, misconception_detected, and mastery_breakthrough events injected into future tutor prompts.
  • Self-Verifying Quiz Pipeline: Generator → SymPy Symbolic Math Verifier → Distractor Validator → Cosine Similarity (>0.85) Novelty Checker (guaranteeing 0% question repetition).
